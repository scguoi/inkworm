# 用户指南

inkworm 的核心流程很简单：准备一篇英文文章，生成课程，然后按中文提示输入英文。

## 启动

```sh
inkworm
```

如果配置缺失或无效，程序会自动进入配置向导。配置完成后会进入学习界面。

可以用自定义数据目录启动：

```sh
INKWORM_HOME=/path/to/inkworm-data inkworm
```

也可以临时指定配置根目录：

```sh
inkworm --config /path/to/inkworm-data
```

## 生成课程

1. 按 `Ctrl+P` 打开命令面板。
2. 输入 `/import` 并回车。
3. 粘贴英文文章。
4. 按 `Ctrl+D` 提交。
5. 等待课程生成完成后开始练习。

文章不能超过配置里的 `generation.max_article_bytes`，默认是 `16384` 字节。

## 练习方式

每个句子会被拆成 3-5 个阶段：

- `keywords`：关键词或核心短语。
- `skeleton`：句子主干。
- `clause`：加入修饰或从句。
- `full`：完整句子。

你看到中文提示后，输入对应英文。答案会做轻度归一化：首尾空白、连续空白、部分引号和句末标点不会影响判断；大小写和句内标点仍然重要。

## 键盘操作

| 操作 | 说明 |
|---|---|
| 输入字符 | 编辑当前答案 |
| `Backspace` | 删除一个字符 |
| `Command+Backspace` | 删除到行首 |
| `Enter` | 提交答案；空答案时重播当前句子 |
| `Tab` | 跳过当前练习 |
| `Ctrl+P` | 打开命令面板 |
| `Ctrl+C` | 保存进度并退出 |
| `Esc` | 关闭弹层；错题模式中暂停复习 |

答对后会自动进入下一题。答错后，任意按键会清空输入并重新开始当前题。

## 课程管理

打开命令面板：

```text
/list
```

在课程列表里用方向键选择课程，按 `Enter` 切换，按 `Esc` 返回。

删除当前课程：

```text
/delete
```

删除只删除课程文件，不会清理所有历史数据。执行前会有确认界面。

## 错题本

普通练习中，同一个练习连续答错两次会进入错题本。

开始错题复习：

```text
/mistakes
```

错题复习会按当天会话推进。错题需要在多个合格学习日里保持正确，才会从错题本移除。

## TTS 朗读

TTS 有三种临时模式：

```text
/tts auto
/tts on
/tts off
```

- `auto`：根据当前音频输出设备决定是否朗读。
- `on`：本次运行强制尝试朗读。
- `off`：本次运行关闭朗读。

这些命令只影响当前进程，不会写入 `config.toml`。如需长期修改，请使用 `/config` 或直接编辑配置文件。

## 健康检查

运行：

```text
/doctor
```

它会检查配置文件、LLM API key、数据目录、TTS 凭据、音频设备和日志文件。
